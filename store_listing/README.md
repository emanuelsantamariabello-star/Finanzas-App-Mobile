# Material de la ficha de Google Play

La carpeta `es-CO` contiene los textos candidatos para la ficha en español.
Los recursos reproducibles se generan con:

```powershell
.\tools\generate_store_assets.ps1
.\tools\validate_play_store_assets.ps1
```

## Capturas pendientes

Las capturas deben obtenerse de una compilación real y no contener nombres,
correos, fotografías ni movimientos personales. Se recomienda capturar:

1. Inicio y resumen financiero.
2. Lista de movimientos.
3. Estadísticas.
4. Recordatorios.
5. Metas y presupuestos.
6. Perfil y configuración.

Usar un dispositivo Android con resolución uniforme, datos ficticios y barras
del sistema limpias. La selección final se valida en Play Console porque sus
requisitos pueden cambiar.
